A wrapper class in Java is a class that wraps a primitive data type inside an object.
Wrapper classes allow primitive values to be used as objects, especially in collections like ArrayList, HashMap, HashSet, etc.
Primitive = simple value
Wrapper class = object containing that value

Primitive → Wrapper
Primitive	Wrapper class
int	Integer
double	Double
char	Character
boolean	Boolean
float	Float
long	Long
short	Short
byte	Byte


Java automatically converts a primitive into its wrapper:
int x = 5;
Integer y = x;
