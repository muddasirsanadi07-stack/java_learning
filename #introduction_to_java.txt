What is Java? original name Oak
Java is a high-level, general-purpose, class-based, object-oriented programming language and runtime ecosystem.

High-level → you write instructions relatively close to human thinking,rather than CPU instructions
General-purpose → it can be used for backend systems, Android historically, enterprise software, tools, desktop applications, etc.
strong OOPs concepts

Java source code
       ↓
     javac    (java langauge compiler)
       ↓
   Bytecode (.class)
       ↓
      JVM    (java virtual machine)---translates platform-independent bytecode into native machine code specific to your computer's CPU architecture using its Execution Engine,
            (JIT(just in time |a compiler-subpart of jvm) compilation into native machine code.)
       ↓
Machine code
       ↓
      CPU

    Platform independence
    Mature ecosystem
    Automatic memory management--Garbage collection reduces manual memory-management errors.

    good concurrency
    robut tooling 
    huge exterprise presence

Disadvantages of Java
    More memory consumption
    overhead
    leghty coding-verbosity
    JVM dependency
    Abstraction overhead
